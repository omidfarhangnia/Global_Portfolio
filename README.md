# 🌍 پورتفولیو گلوبال | Global Portfolio Clone

این پروژه یک کلون از یک قالب آنلاین است که با هدف اصلی پیاده‌سازی انیمیشن‌های روان و جذاب در رابط کاربری توسعه داده شده است. این یک تمرین عملی برای به کارگیری کتابخانه قدرتمند **GSAP (GreenSock Animation Platform)** و خلق انیمیشن‌های تعاملی و مبتنی بر اسکرول برای بهبود تجربه کاربری است.

## ✨ ویژگی‌های کلیدی و انیمیشن‌ها

- **🚀 انیمیشن ورودی (Intro):** انیمیشن‌های جذاب هنگام بارگذاری اولیه صفحه برای جلب توجه کاربر.
- **🖱️ انیمیشن‌های مبتنی بر اسکرول:** نمایش پویای المان‌ها و بخش‌های مختلف سایت همزمان با اسکرول کاربر.
- **✨ افکت‌های شناور (Hover Effects):** افکت‌های انیمیشنی تعاملی بر روی دکمه‌ها، کارت‌ها و لینک‌ها.
- **Timeline کنترل‌شده با GSAP:** استفاده از `GSAP Timeline` برای مدیریت دقیق و هماهنگ‌سازی چندین انیمیشن پیچیده.
- **📱 طراحی کاملاً واکنش‌گرا:** اطمینان از اجرای صحیح و روان انیمیشن‌ها در
